## 이번 판의 흐름

상품 링크·이미지 → 에이전트 소스 후보 → 원출처·모델·사용 범위 확인 → 소재·리믹스 설정 → 초안 → 채팅 개선 → 발행·직접 게시 → 카페 인증.

대본에서 현재 자동 영상 발행으로 소개한 곳은 **유튜브 쇼츠·네이버 클립**이다. 인스타그램·스레드·틱톡은 추가 예정으로 구분해 완성 파일을 직접 올리는 기본 흐름으로 설명했다. 챌린지 게시 대상은 5곳, 네이버 카페는 인증 장소다.

매일 목표·준비물·실행 순서·프리즘 요청·상품 예시·제출물·완료 기준이 있다. 30일 목표는 영상30개·게시150건·인증30개이며 실제 완료와 미완료는 구분한다. 엑셀 진행표에서 날짜를 누르면 DAY 시트로 이동한다.

음악·템플릿·예약·작업·기억·블로그·키워드·하이라이트·원격·요금 안내는 필요한 사람의 확장 과정으로 정리했다. 블로그 대량 발행을 매일 영상 과제에 추가하지 않았다.

## 자료와 판매 범위

제공된 라이브 대본의 기능 설명을 반영했으며 실제 프로그램 실행·배포 버전·성능·최신 플랫폼 정책을 독립 검증한 판은 아니다. 현재 소개와 추가 예정 기능을 구분했다. 성능 비교, 정지 방지, 결과 검증 불필요 등의 주장을 판매 보장으로 쓰지 않았다. 원문 대본 파일 자체는 공개하지 않았다.

판매글은 10명·1인15만원·30일 챌린지 모집용이다. 프로그램과 AI 비용의 포함 여부, 배포 버전·시작일·교육·질문·피드백·신청·결제·환불 조건은 실제 운영 안내로 확정한다. 소스 권리, 상품 조건, 광고·제휴 표시와 실제 발행 상태를 확인한다.

v2·v3는 보관했고 일반 파일명 `shopping-shortform-ebook.pdf`와 `shopping-shortform-package.zip`은 최신 프리즘판으로 갱신했다.
