## 하루에 하는 일

상품을 고르고, 쓸 영상을 준비한다. 프리즘으로 초안을 만든 뒤 마음에 안 드는 부분을 고친다. 완성 파일을 다섯 곳에 올리고 네이버 카페에 링크와 오늘 한 일을 남긴다.

다섯 곳은 유튜브·인스타그램·틱톡·스레드·네이버 클립이다. 유튜브·클립은 지원되는 프리즘 업로드 기능을 확인해 사용하고, 나머지 세 곳은 직접 올린다.

30일 목표는 영상 30개, 게시 150건, 인증글 30개다. 실제 끝낸 수는 따로 적는다. 엑셀은 진행표에서 오늘 주제를 누르면 해당 날짜 시트가 열린다.

## 자료와 운영 안내

기능은 10월 12일 라이브 설명을 바탕으로 정리했다. 실제 프로그램 실행이나 최신 플랫폼 정책을 모두 확인한 자료는 아니다. 메뉴·지원 범위·요금은 사용하는 버전에서 확인한다. 영상의 사용 허락, 상품 정보와 광고·제휴 표시도 살펴본다.

판매글은 10명·1인 15만원·30일 챌린지 모집용이다. 일정, 질문과 피드백, 프로그램·AI 비용 포함 여부, 신청·결제·환불 방법은 실제 운영 조건으로 확정한다.

이전 판은 보관했다. 일반 파일명 `shopping-shortform-ebook.pdf`와 `shopping-shortform-package.zip`은 이번 판으로 갱신했다.
