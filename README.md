## 이번 판의 진행 방식

1. 기존 쇼핑 숏폼에서 상품과 아이디어를 찾습니다.
2. 핀터레스트·더우인·샤오홍슈·틱톡·아마존·인스타그램·스레드에서 원출처와 사용 범위를 확인한 영상·이미지 소스를 확보합니다.
3. Shorts Studio의 배포 버전에서 지원하는 방식으로 대본·음성·자막·장면을 구성합니다. 상품 구매 후 직접 촬영은 선택 과정입니다.
4. **유튜브·인스타그램·틱톡·스레드·네이버 클립, 총 5곳**에 게시합니다.
5. 네이버 카페에 다섯 게시 링크와 작업 기록을 남깁니다.

30일 목표는 영상 30개, 게시 150건, 카페 인증글 30개입니다. 실제 완료 수와 미완료 이유는 따로 기록합니다.

## Shorts Studio 설명 범위

운영자가 제공한 기능 설명을 반영했습니다. 상품·소재 기반 다중 소스 제작, 기존 영상 재가공(세탁기), 롱폼의 숏폼화라는 세 가지 방향을 설명합니다.

현재 로컬 영상·준비된 대본과 음성을 불러와 편집·렌더링하는 제한 제작 경로와, 추가 개발·검증 중인 자동 기능을 구분했습니다. 실제 프로그램 UI나 배포 버전을 이 작업에서 테스트하지 않았으며 설치·접속·실제 화면·카페 주소·교육 일정은 운영자의 안내로 확정해야 합니다.

영상 소스의 다운로드 가능 여부와 상업적 편집·재게시 권한은 별도로 확인해야 합니다. 플랫폼의 최신 자격·기능·정책을 검증 완료한 판은 아닙니다.

전체 ZIP에는 PDF·Word·Markdown·HTML 원고, 엑셀·CSV 기록표, 카페 인증 양식, 운영안과 모집글 수정본이 포함됩니다. 이전 일반 파일명 `shopping-shortform-ebook.pdf`와 `shopping-shortform-package.zip`도 이번 개정판으로 갱신했습니다.
