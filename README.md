## 매일 무엇을 하는가

각 날짜에는 목표·준비물·단계별 실행·상품 예시·카페 제출물·완료 기준이 있다.
엑셀의 진행표에서 날짜를 누르면 해당 날짜 시트로 이동한다. 상세 날짜 시트 외에 소스 카드, 게시 기록 150행, 카페 인증 기록을 제공한다.

진행 흐름은 상품과 영상 찾기 → 원출처·허락 확인 → 사용 가능한 소스 준비 → Shorts Studio 제작 → 유튜브·인스타그램·틱톡·스레드·네이버 클립 게시 → 네이버 카페 인증이다. 직접 구매·촬영은 선택한다.
30일 목표는 영상 30개, 게시 150건, 카페 인증 30개이며 실제 완료와 미완료 사유는 구분한다.

## 판매글의 범위

판매글은 **10명·1인 15만원·30일 챌린지 모집용**이다. 전자책 단독 가격은 정해지지 않아 넣지 않았다. 시작일·교육 일정·질문과 피드백 범위·추가 비용·신청/결제/환불 조건은 실제 운영 안내로 확정한다. 수익이나 조회수를 보장하지 않는다.

Shorts Studio는 현재 개발·사용자 검증 중이다. 현재 가능한 제한 제작 경로와 추가 개발 중인 자동 기능을 구분해 설명했다. 실제 UI나 배포 버전을 이 작업에서 테스트한 것은 아니다. 소스 사용 범위, 상품 조건, 광고·제휴 표시와 플랫폼의 현재 기능을 확인해야 한다. 최신 정책 검증 완료판으로 표시하지 않는다.

이전 v2 파일은 남겨두었고, 일반 파일명 `shopping-shortform-ebook.pdf`와 `shopping-shortform-package.zip`은 최신 v3으로 갱신했다.
