# 처음에는 영상 한 편이면 된다

잘 만들려고 오래 고민하기보다, 한 편을 끝까지 만들어본다.

쇼핑 숏폼을 시작하려고 검색하다 보면 영상만 잔뜩 저장하게 된다. 괜찮은 상품은 찾았는데, 막상 만들려니 어디서부터 손을 대야 할지 모르겠다. 이 챌린지는 그다음 일을 하나씩 해보는 과정이다.

먼저 상품 하나를 고른다. 쓸 수 있는 영상을 준비하고, 프리즘으로 초안을 만든다. 마음에 안 드는 부분은 고친 뒤 다섯 곳에 올린다. 마지막에는 네이버 카페에 오늘 한 일을 남긴다.

처음부터 프로그램의 모든 기능을 알 필요는 없다. “프리즘 프로그램 설명해줘”라고 물어보고, 오늘 영상에 필요한 설정부터 익히면 된다. 에이전트는 이렇게 질문을 받고 작업을 도와주는 AI다.

> 매일 할 일은 같다.
> 영상 한 편 만들기 → 유튜브·인스타그램·틱톡·스레드·클립에 올리기 → 카페에 인증하기.

유튜브 쇼츠와 네이버 클립은 프리즘의 업로드 기능을 확인해 사용한다. 인스타그램·틱톡·스레드는 완성된 파일을 직접 올린다. 새 기능이 나오면 운영자가 사용할 수 있는 방법을 안내한다.

> 이 책의 기능 안내는 10월 12일 프리즘 라이브 설명을 기준으로 정리했다. 실제 메뉴와 지원 범위는 사용하는 버전에서 확인한다.

# 하루 한 편을 이렇게 완성한다

영상 다섯 개를 새로 만드는 게 아니라, 한 편을 다섯 곳에 올린다.

1. 상품을 고른다. 이미 올라온 쇼핑 숏폼을 보며 어떤 불편을 해결하는지 살펴본다. 오늘 만들 상품은 하나면 충분하다.
2. 쓸 영상을 준비한다. 처음 만든 사람과 사용 허락을 확인하고, 상품 모델도 맞춰본다.
3. 프리즘으로 만든다. 장면과 설명을 정해 초안을 만든다. 저장하기 전에 자막과 소리까지 한 번 본다.
4. 다섯 곳에 올린다. 플랫폼마다 상품 안내와 광고 표시가 맞는지 확인한다.
5. 카페에 남긴다. 게시 링크, 걸린 시간, 오늘 배운 점을 적는다. 못 올린 곳이 있으면 이유도 함께 남긴다.

> 오늘 끝나면 남아야 할 것｜완성 영상 1개, 게시 링크 최대 5개, 카페 인증글 1개.

처음에는 시간이 오래 걸려도 괜찮다. 검색에서 오래 걸렸는지, 편집에서 막혔는지만 적어둔다. 며칠 해보면 다음에 줄일 부분이 보인다.

# 시작하기 전에 이것부터 준비한다

첫날부터 로그인과 설치에 시간을 다 쓰지 않도록 미리 확인한다.

1. 프리즘을 준비한다. 운영자가 안내한 설치 방법을 따른다. Windows부터 배포하는 것으로 안내돼 있으므로 Mac 사용자라면 먼저 사용 가능한 버전을 확인한다.
2. AI를 연결한다. 지원되는 구독 계정이나 API 연결 중 사용할 방법을 고른다. 어떤 것을 연결해야 할지 모르겠다면 운영자의 기본 안내부터 따른다.
3. 업로드할 계정을 확인한다. 유튜브·인스타그램·틱톡·스레드·네이버 클립에 로그인해본다. 프리즘으로 올릴 계정과 직접 올릴 계정을 구분해둔다.
4. 카페에 가입한다. 인증 게시판을 찾아두고 등업이나 가입 승인이 필요하면 미리 끝낸다.
5. 첫 상품과 영상을 준비한다. 사용할 수 있는 예제 영상이 있다면 그걸로 시작해도 된다. 상품 정보와 사용 허락 기록은 같은 폴더에 둔다.

프로그램 이용료와 AI 비용이 참가비에 포함되는지는 모집 안내를 확인한다. API 키나 비밀번호는 카페에 올리지 않는다.

> 처음에는 계정 하나, 작업 하나로 시험한다. 한 편이 끝까지 만들어지는지 본 다음 작업을 늘리면 된다.

# 어떤 상품부터 만들면 좋을까

첫 상품은 사용 장면이 잘 보이는 것으로 고른다.

“잘 팔리는 상품”만 찾으려고 하면 끝이 없다. 처음에는 내가 설명할 수 있는 불편부터 고르는 편이 쉽다. 충전선이 자꾸 떨어진다면 케이블 정리, 서랍이 어지럽다면 서랍 수납처럼 검색한다.

| 불편한 상황 | 찾아볼 말 | 쓸 만한 장면 |
| --- | --- | --- |
| 충전선이 책상 뒤로 떨어진다 | 케이블 홀더 / cable organizer | 선을 끼우고 다시 꺼내는 모습 |
| 서랍에서 작은 물건이 섞인다 | 서랍 칸막이 / drawer organizer | 물건을 나눠 넣는 모습 |
| 모서리 먼지가 잘 안 닦인다 | 틈새 브러시 / cleaning brush | 도구가 닿는 부분 |
| 가방에서 물건을 찾기 어렵다 | 가방 파우치 / bag organizer | 넣고 꺼내는 모습 |

상품 이름이 바로 보이고, 어떻게 쓰는지도 이해된다면 좋은 첫 후보가 된다. 여기에 원래 영상을 만든 사람과 정확한 모델까지 찾을 수 있는지 살펴본다.

> 후보는 세 개만 저장해본다. 그중 오늘 쓸 수 있는 하나를 고른다. 나머지는 다음에 써도 된다.

# 편집에 쓸 영상을 소스라고 부른다

참고로 본 영상과 실제로 사용할 파일은 나눠둔다.

소스는 영상을 만들 때 쓰는 재료다. 상품을 펴는 장면, 설치하는 장면, 쓰는 모습을 찍은 파일이 여기에 들어간다. 사진도 영상 사이에 넣을 재료가 될 수 있다.

이미 올라온 쇼핑 숏폼은 상품을 찾고 구성을 살펴보는 데 참고한다. 그 영상에 들어간 장면을 내가 쓰려면, 처음 만든 사람이 누구인지 찾아 사용 범위를 확인한다.

| 찾은 자료 | 어떻게 쓰는가 |
| --- | --- |
| 참고 영상 | 상품과 장면 아이디어를 살펴본다 |
| 원래 만든 사람·업체 | 편집해서 올려도 되는지 물어본다 |
| 사용이 허락된 원본 | 프리즘에 넣어 제작한다 |

다운로드 버튼이 있다고 바로 다시 올려도 되는 것은 아니다. 자막을 바꾸거나 목소리를 넣어도 원래 영상의 권리는 남는다. 허락을 받을 때는 편집과 광고·제휴 활용, 다섯 플랫폼 게시까지 함께 물어본다.

> 출처를 못 찾았거나 허락이 아직 안 된 영상은 참고 폴더에 둔다. 오늘 제작에는 준비된 다른 소스를 쓰면 된다.

# 핀터레스트와 더우인에서 상품 영상을 찾아본다

상품 이름이 다르게 올라올 수 있으니 모양과 사용 장면도 본다.

## 핀터레스트

“desk cable organizer”나 “small kitchen storage”처럼 상품과 상황을 함께 검색한다. 쓸 만한 영상을 찾으면 핀에 연결된 페이지와 계정 소개를 열어본다. 다시 올린 자료라면 원래 만든 사람까지 찾아간다.

## 더우인

중국어 검색어를 함께 쓰면 찾기 쉬울 때가 있다. “桌面收纳”는 책상 정리, “厨房收纳”는 주방 수납, “数据线收纳”는 케이블 정리라는 뜻이다. 상품이 어떻게 움직이고 어디에 쓰이는지 보며 후보를 고른다.

1. 상품이 보이는 게시물 주소를 저장한다.
2. 계정과 브랜드를 보고 누가 만든 영상인지 찾는다.
3. 편집해서 올려도 되는지 물어보고 허락된 원본을 받는다.

> 상품 이름, 게시 주소, 만든 사람, 쓸 장면, 허락받은 내용을 메모한다. 저장한 영상이 많아지면 이 다섯 줄이 도움이 된다.

접속이나 다운로드가 제한돼 있다면 우회하려고 시간을 쓰지 않는다. 다른 후보를 찾거나 만든 사람에게 원본을 요청한다.

# 샤오홍슈와 틱톡에서 쓰는 모습을 살펴본다

멋진 화면보다 설명에 쓸 장면을 찾는다.

## 샤오홍슈

샤오홍슈의 중국어 이름은 “小红书”다. 상품 이름에 “收纳”(수납), “好物”(추천 물건), “使用”(사용)을 더해 찾아볼 수 있다. 설치하고 꺼내 쓰는 장면부터 살펴본다.

## 틱톡

상품 이름이나 “cable organizer”, “kitchen organizer”처럼 구체적인 말로 검색한다. 영상과 글에서 브랜드·모델·원래 만든 계정을 찾아본다.

개인 후기와 브랜드 자료는 구분한다. 다른 사람이 찍은 후기는 판매자가 마음대로 사용을 허락할 수 있는 자료가 아닐 수 있다. 실제로 만든 사람에게 확인한다.

> 마음에 드는 영상은 먼저 주소를 남긴다. 저장 버튼이 있어도 다시 올리는 허락은 따로 받는다. 허락된 파일을 받아 제작 폴더에 넣는다.

파일을 못 받았으면 참고 자료로 두고 다른 소스를 고른다. 오늘 한 편을 만드는 데 검색 장소를 모두 익힐 필요는 없다.

# 아마존에서는 누가 올린 영상인지 본다

상품 페이지에 있다고 모두 판매자의 영상은 아니다.

상품 이름으로 검색한 뒤 상세 페이지의 영상을 살펴본다. 제품을 펴고 조립하고 사용하는 장면이 있으면 설명하기 쉬운 후보가 될 수 있다.

1. 브랜드와 모델, 크기와 구성을 적는다.
2. 브랜드 영상인지 구매자가 올린 후기인지 본다.
3. 브랜드 자료는 권리를 가진 업체에, 개인 후기는 촬영한 사람에게 사용을 물어본다.

판매자가 제품을 판다고 그 페이지의 모든 후기를 허락할 수 있는 것은 아니다. 메시지에 “직접 제작하신 자료인가요?”를 함께 넣으면 확인하기 편하다.

> 문의 예시
> “상품 소개 영상을 편집해 유튜브·인스타그램·틱톡·스레드·클립에 올리고 싶습니다. 직접 제작하신 자료라면 원본과 사용 가능한 범위를 알려주실 수 있을까요?”

아마존에서 찾은 제품과 국내에서 연결할 상품도 비교한다. 같은 모델을 찾을 수 없다면 링크를 붙이는 후보에서는 잠시 빼둔다.

# 인스타그램과 스레드에서는 원래 만든 계정을 찾는다

저장한 게시물은 다시 찾아볼 자료다. 제작용 파일은 따로 받는다.

## 인스타그램

상품 이름과 관련 키워드로 릴스를 찾는다. 설명, 태그된 브랜드, 계정 소개를 보면 원래 만든 사람을 찾는 데 도움이 된다. 다른 영상을 모아 올리는 계정이라면 그곳에서 끝내지 않는다.

## 스레드

사용 이야기와 영상, 연결된 인스타그램 계정을 함께 본다. 직접 올린 자료인지 다른 게시물을 가져온 것인지 구분하고, 실제 촬영한 사람에게 연락한다.

1. 상품 정보와 게시 주소를 저장한다.
2. 처음 만든 사람에게 편집과 상업적 게시를 물어본다.
3. 허락받은 파일과 답장 내용을 함께 보관한다.

> 북마크는 나중에 찾아보는 기능일 수 있다. 파일을 받았는지와 다시 올려도 되는지는 별도로 확인한다.

짧게 문의해도 사용 목적은 분명히 적는다.

> 직접 제작하시거나 사용을 허락할 권리가 있는 자료인가요? 가능하다면 원본 파일과 편집·상업적 게시가 가능한 범위를 알려주세요.
> 사용 기간, 출처 표시, 음악·출연자에 관한 제한도 부탁드립니다.

답장이 오면 누가 허락했는지, 어디에 쓸 수 있는지, 제한이 있는지를 본다. 여러 플랫폼에 올릴 예정이라면 그 이름까지 함께 확인한다.

“써도 된다”는 말만 있고 광고나 편집 이야기가 빠졌다면 한 번 더 물어본다. 답장을 받지 못한 파일은 잠시 보류하고 다른 소스를 쓴다.

> 허락받은 메시지는 영상과 같은 폴더에 둔다. 시간이 지나면 어디서 받은 자료인지 헷갈리기 쉽다.

---

# 받은 파일은 이렇게 모아둔다

다음 날 다시 찾느라 시간을 쓰지 않게 이름과 위치를 정해둔다.

영상이 몇 개만 쌓여도 어떤 상품인지 헷갈린다. 상품별 폴더를 만들고 받은 영상, 상품 정보, 사용 허락 기록을 함께 넣는다. 파일 이름도 비슷한 규칙으로 붙여두면 찾기 쉽다.

| 적어둘 것 | 예시 |
| --- | --- |
| 상품 | 케이블 홀더 / 정확한 모델과 옵션 |
| 원본 주소 | 처음 올린 게시물 주소 |
| 파일 이름 | D01_cable_source.mp4 |
| 쓸 장면 | 선 끼우기 / 꺼내기 / 다시 놓기 |
| 사용 허락 | 어디까지 허락받았는지와 기록 위치 |
| 더 확인할 것 | 음악·출연자·기간·표시 조건 |

받은 파일은 끝까지 한 번 재생한다. 화면이 깨져 있거나 제품이 잘렸다면 필요한 장면을 다시 요청한다. 음악과 로고가 들어 있다면 그 부분까지 사용해도 되는지 살펴본다.

> 편집할 파일과 참고만 할 영상을 섞지 않는다. 폴더만 나눠도 실수를 꽤 줄일 수 있다.

---

# 비슷하게 생겨도 같은 상품인지 먼저 본다

영상에 나온 제품과 연결할 상품이 맞아야 한다.

이름이 같아도 크기나 구성이 다를 수 있다. 영상에는 작은 제품이 나오는데 링크는 큰 제품으로 연결되면 보는 사람이 헷갈린다. 브랜드·모델·옵션을 먼저 맞춘다.

1. 영상 속 제품의 이름과 모델을 찾는다.
2. 연결할 상품의 크기·구성·개수를 비교한다.
3. 설치할 곳이나 호환 조건처럼 구매 전에 봐야 할 내용을 하나 적는다.
4. 같은 모델을 연결할 수 없다면 링크를 바꾸거나 다른 상품을 고른다.

> 직접 써본 적이 없다면 “제가 써보니”라고 말하지 않는다. “이 장면에서는 선을 꺼내고 다시 놓는다”처럼 화면에서 볼 수 있는 일을 설명하면 된다.

“무조건 좋다”, “어디든 맞는다”는 말보다 어떤 상황에서 쓰고 무엇을 먼저 확인해야 하는지 알려주는 편이 낫다.

---

# 일반·리믹스·하이라이트 어떤 모드를 쓸까

이번 챌린지는 리믹스부터 익힌다.

| 모드 | 쉽게 말하면 | 써볼 상황 |
| --- | --- | --- |
| 일반 | 주제나 자료에서 영상을 만든다 | 상품과 사용 상황을 설명할 때 |
| 리믹스 | 준비한 영상들을 새 흐름으로 엮는다 | 상품 사용 장면을 모아 만들 때 |
| 하이라이트 | 긴 영상에서 쓸 구간을 고른다 | 제품 설명의 핵심만 짧게 만들 때 |

쇼핑 숏폼은 상품 사용 장면이 중요하다. 허락된 소스를 모아 리믹스로 초안을 만들고, 설명과 장면이 잘 맞는지 보면서 고친다. 채팅으로 요청해도 되고 설정 화면에서 직접 골라도 된다.

> 처음에는 이렇게 묻는다.
> “이 상품 영상으로 리믹스 한 편을 만들고 싶어. 필요한 설정부터 알려줘.”

AI 모델과 음성, 음악을 한꺼번에 바꾸려 하지 않는다. 운영자가 안내한 기본 설정으로 한 편을 만든 다음, 마음에 안 드는 부분부터 바꾸면 된다.

---

# 처음부터 잘 만들기보다 초안을 보고 고친다

프리즘에 맡길 일과 내가 볼 일을 나누면 훨씬 덜 막힌다.

1. 상품 링크나 이미지를 준비한다. “이 상품의 원본이나 관련 영상을 찾아줘”라고 요청한다.
2. 나온 영상들을 본다. 같은 모델인지, 누가 만든 자료인지, 내가 편집해 올려도 되는지 확인한다.
3. 쓸 파일을 소재함에 모은다. 어떤 장면을 쓸지 짧게 메모한다. 소재함은 제작에 쓸 파일을 모아두는 곳이다.
4. 리믹스 모드와 모델·음성을 고른다. 오늘은 쉽게 설명할지, 가벼운 농담을 넣을지도 정한다.
5. 초안을 재생한다. 첫 장면, 긴 설명, 읽기 어려운 자막 중 거슬리는 부분 하나를 고쳐달라고 한다.
6. 다시 보고 저장한다. 업로드한 뒤에도 재생해보고 카페에 링크를 남긴다.

> “더 좋게 해줘”보다 이렇게 말하는 편이 낫다.
> “첫 설명을 줄이고 사용 장면부터 보여줘. 제품 크기와 설치 조건은 그대로 두고.”

---

# 원하는 느낌을 먼저 말해준다

설명형으로 시작하고, 익숙해지면 다른 느낌도 시도한다.

## 쉽게 설명하고 싶을 때

> “처음 보는 사람도 이해하게 설명해줘. 영상에 보이는 사용법을 짧게 말하고, 구매 전에 볼 조건 하나를 넣어줘.”

## 조금 재치 있게 만들고 싶을 때

> “선 찾느라 책상 밑을 뒤지는 상황을 가볍게 표현해줘. 농담은 한 번만 넣고, 사용법은 분명하게 알려줘.”

## 짧은 이야기로 만들고 싶을 때

> “충전선을 찾는 상황에서 시작해서, 선을 둘 자리를 정하는 방법으로 이어줘. 실제 장면으로 설명하고 지어낸 상황은 예시라는 걸 알 수 있게 해줘.”

말투가 마음에 안 들면 그것부터 고쳐도 된다. “너무 거창하다. 평소 말하듯 짧게 써줘”처럼 구체적으로 말한다. 다만 재미있게 바꾸더라도 없는 경험이나 성능을 덧붙이지 않는다.

마음에 든 설정은 다음 작업에서도 쓸 수 있게 저장한다. 상품 정보와 링크처럼 바뀔 수 있는 내용은 매번 다시 본다.

---

# 링크 하나를 넣고 쓸 영상을 찾아본다

상품 정보가 정확할수록 후보를 비교하기 편하다.

상품 링크나 이미지를 넣고 관련 영상을 요청한다. 쿠팡 파트너스나 쇼핑커넥트 링크를 준비했다면 그 정보로 시작할 수도 있다.

> “이 상품과 같은 모델의 원본이나 관련 영상을 찾아줘. 게시물 주소도 같이 보여줘. 다른 옵션이거나 출처가 불분명하면 따로 표시해줘.”

1. 찾아준 영상에서 상품 모양과 옵션을 비교한다.
2. 원래 만든 사람에게 편집과 상업적 게시가 가능한지 확인한다.
3. 쓸 장면이 있는 파일을 받고, 허락 기록과 함께 저장한다.
4. 처음에는 1~3개만 고른다. 부족한 장면이 생기면 그때 더 찾는다.

핀터레스트·더우인·샤오홍슈·아마존·인스타그램·스레드에서도 직접 찾아볼 수 있다. 이 사이트를 모두 프리즘이 자동 수집한다고 생각하지는 않는다. 지원되는 검색과 직접 검색을 함께 쓰면 된다.

---

# 저장하기 전에 처음부터 끝까지 본다

자동으로 만들어졌어도 마지막 확인은 내가 한다.

| 볼 부분 | 살펴볼 것 |
| --- | --- |
| 설명 | 안 써본 제품을 써봤다고 말하지 않는가 |
| 상품 정보 | 모델명·숫자·단위가 맞는가 |
| 장면 | 말하는 기능이 화면에도 보이는가 |
| 자막·음성 | 읽고 듣는 내용이 맞는가 |
| 음악 | 이 영상에 써도 되는 음악인가 |
| 마지막 안내 | 실제로 누를 수 있는 곳을 알려주는가 |

처음에는 소리를 켜고 한 번 본다. 그다음 소리를 끄고 자막만 읽어본다. 한쪽에서만 이해된다면 설명이나 자막을 손볼 필요가 있다.

> 고칠 곳을 찾았으면 한 번에 하나씩 말한다.
> “모델명이 틀렸다. 이 이름으로 고쳐줘.”
> “자막이 너무 길다. 짧게 나눠줘.”

수정됐다는 메시지만 보고 끝내지 않는다. 다시 나온 파일을 재생해 내가 말한 부분이 바뀌었는지 본다.

---

# 케이블 홀더로 한 편을 만들어보자

상품은 달라도 만드는 순서는 같다.

책상에서 충전선을 쓰다 놓으면 선 끝이 뒤로 떨어진다. 케이블 홀더는 선을 둘 자리를 정하는 상품이다. 이 문제와 사용 장면을 연결해 첫 영상을 만들어본다.

1. 정확한 모델과 상품 링크를 준비한다. 프리즘에 관련 영상을 찾아달라고 한다.
2. 선을 끼우고 꺼내는 장면을 고른다. 원래 만든 사람과 사용 범위를 확인한 소스만 쓴다.
3. 리믹스 모드로 “문제 → 사용 모습 → 확인할 조건” 순서의 초안을 만든다.
4. 처음 설명이 길면 사용 장면을 앞으로 옮긴다. 자막과 음성을 다시 본다.
5. 저장한 파일을 다섯 곳에 올리고 카페에 링크와 걸린 시간을 남긴다.

> 필요한 장면이 없으면 대본을 바꾼다. 선이 떨어지는 컷이 없다면 “선 끝을 둘 자리를 정하는 도구”라는 설명으로 시작해도 된다.

처음부터 세련된 효과를 넣을 필요는 없다. 무슨 상품이고 어떻게 쓰는지 보이면 첫 연습으로 충분하다.

---

# 대본은 짧게 쓰고 장면에 맞춰 읽어본다

한 영상에서 한 가지 불편만 설명해본다.

| 순서 | 문장 예시 | 쓸 화면 |
| --- | --- | --- |
| 시작 | 충전선을 놓으면 자꾸 책상 뒤로 떨어진다. | 선이 떨어지는 실제 장면 |
| 방법 | 선 끝을 둘 자리를 정하는 홀더다. | 상품이 보이는 장면 |
| 사용 | 선을 꺼내 쓴 뒤 다시 홈에 놓는 방식이다. | 꺼내고 놓는 모습 |
| 조건 | 설치할 표면과 선 굵기는 먼저 확인한다. | 조건 자막이나 관련 장면 |
| 안내 | 같은 모델의 정보는 [실제 안내]에서 볼 수 있다. | 플랫폼에 맞는 안내 |

문장대로 보여줄 장면이 없다면 문장을 고친다. 선이 떨어지는 컷이 없는데 그런 장면을 보여줬다고 말할 필요는 없다. 있는 사용 컷부터 시작해도 된다.

직접 써본 영상이 아니면 내 경험처럼 설명하지 않는다. 화면에서 보이는 행동과 확인한 상품 정보를 말하면 충분하다.

> 길이를 억지로 채우지 않는다. 설명할 내용이 끝났으면 마무리한다. 짧아도 사용법과 조건이 보이면 된다.

---

# 다른 상품도 같은 순서로 써본다

아래 문장은 실제 소스와 상품 정보에 맞게 바꾼다.

## 서랍 칸막이

> “작은 물건을 찾으려면 서랍을 한참 뒤지게 된다. 칸을 나눠두면 물건을 둘 자리가 정해진다. 쓰기 전에는 서랍 안쪽 크기와 높이를 확인한다.”

설치하고 물건을 넣는 장면을 쓴다. 정리한 뒤에도 꺼내기 쉬운지 보이는 컷이 있으면 함께 넣는다.

## 틈새 브러시

> “천이 잘 닿지 않는 모서리가 있다. 이 브러시는 좁은 부분을 닦는 데 쓰는 도구다. 어느 부분에 닿는지 보고, 사용할 표면과 재질도 확인한다.”

청소 장면에 없는 효과를 추가하지 않는다. 세제를 썼다면 도구만으로 닦인 것처럼 설명하지 않는다.

## 접이식 바구니

> “안 쓰는 바구니도 자리를 차지한다. 이 제품은 비운 뒤 접어서 보관하는 방식이다. 펼친 크기와 접힌 크기를 같이 보고 둘 공간을 확인한다.”

같은 자리에서 펼치고 접는 모습이 있으면 비교하기 쉽다. 규격은 상품 정보로 확인하고 임의로 넣지 않는다.

---

# 첫 문장은 상황이 보이면 된다

큰 말을 붙이기보다 시청자가 겪을 만한 일을 꺼낸다.

| 주제 | 시작 문장 예시 |
| --- | --- |
| 충전선 | 선 끝이 자꾸 책상 뒤로 떨어진다. |
| 서랍 | 정리해도 작은 물건이 다시 섞인다. |
| 주방 | 수세미를 둘 자리가 마땅치 않다. |
| 청소 | 이 모서리는 천으로 닦기 어렵다. |
| 가방 | 작은 물건 하나 찾으려 가방을 다 비운다. |
| 접이식 제품 | 안 쓸 때 어디에 둘지도 생각해본다. |

두 문장을 써보고 첫 화면에 더 잘 맞는 것을 고른다. “최고의 상품”, “삶이 달라지는 제품” 같은 말이 없어도 상황이 분명하면 시작할 수 있다.

> 끝에서는 실제로 볼 수 있는 곳을 알려준다. 상품 태그가 있으면 태그, 프로필 목록이 있으면 목록을 말한다. 둘 다 없다면 구매 전 조건을 정리하고 끝낸다.

---

# 직접 찍는 편이 쉬운 날도 있다

상품을 살 수 있고 촬영할 여유가 있으면 선택해본다.

받은 소스만으로 크기나 사용법이 잘 안 보일 때가 있다. 그럴 때는 같은 상품을 직접 찍으면 설명하기 쉽다. 집에 이미 가진 제품으로 연습해도 된다.

1. 상품 전체를 찍는다. 손이나 주변 물건과 같이 보이면 크기를 이해하기 쉽다.
2. 쓰는 동작을 찍는다. 펴기, 끼우기, 꺼내기처럼 오늘 설명할 행동 하나면 된다.
3. 전후를 비교한다면 같은 자리와 빛에서 찍는다.
4. 구매 전에 볼 크기나 설치 조건도 보여준다.

흔들리거나 초점이 맞지 않는 컷은 다시 찍는다. 직접 찍은 장면과 외부 소스를 함께 쓰면 어느 부분을 직접 찍었는지 메모해둔다.

> 직접 찍었다면 내 사용 장면이라고 말할 수 있다. 다른 사람의 소스를 썼다면 내가 써본 것처럼 말하지 않는다.

# 유튜브에 올리고 인스타그램에도 올린다

두 곳은 업로드 방법이 다르다.

## 유튜브 쇼츠

1. 완성 영상, 제목, 올릴 채널과 공개 범위를 확인한다. 프리즘 업로드 기능을 쓴다면 대상 채널부터 본다.
2. 필요한 광고·제휴 표시를 적용한다. 상품 태그나 안내도 같은 모델로 맞춘다.
3. 올라간 영상을 직접 재생한다. 공개된 링크를 복사해 카페 메모에 넣는다.

## 인스타그램 릴스

1. 완성 파일을 직접 올리고 커버와 짧은 설명을 넣는다. 자동 업로드는 추가 예정으로 안내돼 있다.
2. 광고·제휴 표시와 필요한 설정을 확인한다. 상품 안내는 실제 사용할 수 있는 프로필 목록 등에 맞춘다.
3. 게시된 화면을 보고 링크를 복사한다.

> 프로그램에서 완료됐다고 나와도 게시된 영상을 한 번 본다. 채널이나 상품 안내가 다르면 바로 고친다.

# 틱톡과 스레드에도 같은 파일을 올린다

필요한 안내 문구만 각 플랫폼에 맞춘다.

## 틱톡

1. 완성 파일과 짧은 설명을 올린다. 상품 홍보에 필요한 공개 설정을 확인한다.
2. 내 계정에 있는 링크나 상품 기능만 안내한다. 게시 후 재생하고 링크를 복사한다.

## 스레드

1. 영상을 첨부하고 어떤 사용 장면인지 한두 문장으로 적는다.
2. 제휴나 협찬이라면 그 내용을 표시한다. 링크를 넣었다면 같은 모델로 열리는지 보고 게시 주소를 복사한다.

> 글 예시
> [필요한 광고·제휴 표시]
> 충전선 끝을 둘 자리를 정하는 홀더다. 설치할 표면과 케이블 굵기는 먼저 확인한다.
> 상품 정보: [정확한 링크 또는 안내]

틱톡과 스레드는 직접 올리는 방법으로 진행한다. 프리즘 지원이 추가되면 운영자가 확인한 방법을 안내한다.

# 클립에 올린 뒤 상품 태그도 눌러본다

업로드 완료와 상품 안내가 맞는지 함께 본다.

1. 클립 계정과 완성 영상, 제목과 글을 확인한다. 사용하는 버전의 업로드 설정을 따른다.
2. 광고·제휴 표시를 넣는다. 상품 태그가 있으면 같은 모델과 옵션을 고른다.
3. 게시된 영상을 재생한다. 태그도 눌러 올바른 상품이 열리는지 본다.
4. 게시 링크를 복사해 카페 인증글에 넣는다.

태그 기능이 없다면 없는 태그를 안내하지 않는다. 제품 정보와 구매 전에 볼 조건을 설명하면 된다.

> 클립은 영상을 올리는 곳이고, 카페는 오늘 한 일을 남기는 곳이다. 클립 업로드가 끝났어도 카페 인증은 따로 한다.

# 제휴나 협찬이면 그 내용을 먼저 알린다

내가 받는 것이 무엇인지에 맞춰 표시한다.

| 상황 | 알릴 내용 |
| --- | --- |
| 구매하면 수수료를 받는다 | 제휴 링크나 태그로 수수료가 생길 수 있다 |
| 제품을 받았다 | 제품을 무상 제공받았다 |
| 제작비를 받았다 | 제작·게시 비용을 받았다 |

> 문구 예시
> “제휴 링크를 통해 구매하면 수수료를 받을 수 있습니다.”
> “제품을 무상 제공받아 소개합니다.”
> “브랜드로부터 제작비를 받은 광고입니다.”

실제 제휴 프로그램에서 정한 문구가 있으면 그 문구를 먼저 확인한다. 영상과 글의 앞부분처럼 알아보기 쉬운 곳에 쓰고, 플랫폼에서 필요한 설정도 적용한다.

여러 관계가 있으면 함께 밝힌다. 영상 소스를 받았다고 제품을 직접 써본 것은 아니므로, 하지 않은 경험은 넣지 않는다.

> 광고를 표시했다고 영상 사용 허락이 생기지는 않는다. 소스를 써도 되는지와 광고 표시는 각각 확인한다.

---

# 카페에는 오늘 한 일을 남긴다

운영자가 알려준 게시판에 하루 한 글을 쓴다.

카페에는 영상을 또 올리기보다, 내가 올린 다섯 링크를 모아둔다. 나중에 보면 어떤 상품을 만들었고 어디서 막혔는지도 찾을 수 있다.

> 제목: [01일차] 닉네임 / 상품명
> 
> 오늘 만든 영상: [제목]
> 상품: [모델과 옵션]
> 사용한 영상: [허락된 소스 / 직접 촬영 / 혼합]
> 유튜브: [링크 또는 못 올린 이유]
> 인스타그램: [링크 또는 못 올린 이유]
> 틱톡: [링크 또는 못 올린 이유]
> 스레드: [링크 또는 못 올린 이유]
> 네이버 클립: [링크 또는 못 올린 이유]
> 광고·제휴 표시: [해당 여부와 확인]
> 프리즘에 요청한 것: [한 문장]
> 고친 부분: [한 가지]
> 작업 시간: [분]
> 오늘 배운 점·질문: [한 문장]

못 올린 곳은 빈칸 대신 이유를 쓴다. “틱톡 업로드 오류, 내일 다시 확인” 정도면 된다. 영상은 올렸는데 상품 링크가 없으면 그 상태도 따로 적는다.

비밀번호, API 키, 개인 주문 정보와 허락받지 않은 원본 파일은 올리지 않는다. 자세한 확인 자료가 필요하면 운영자가 안내한 방법으로 따로 전달한다.

# 바쁜 날에는 설명할 것을 줄인다

오늘 영상에서는 질문 하나만 답해본다.

설치, 크기, 가격, 보관까지 한꺼번에 설명하려고 하면 길어진다. 오늘은 쓰는 모습, 내일은 크기처럼 나누면 대본을 쓰기도 편하다.

1. 전날 상품과 쓸 영상을 정해둔다. 아침부터 검색을 다시 시작하지 않아도 된다.
2. 프로그램을 켜기 전에 첫 문장과 쓸 장면을 적는다.
3. 편집이 끝나면 준비한 게시 문구를 사용한다. 플랫폼마다 상품 안내가 맞는지는 다시 본다.
4. 링크를 카페 양식에 붙이고 오늘 배운 점을 한 줄 남긴다.

하루를 놓쳤다면 못 한 날을 완료했다고 쓰지 않는다. 이유를 적고 다음 날 다시 시작하면 된다. 밀린 숫자를 채우려고 급하게 올리는 것보다 돌아올 순서를 정하는 편이 낫다.

> 시간도 나눠 적는다. 검색 / 제작 / 수정 / 업로드 / 카페 인증. 가장 오래 걸리는 곳 하나부터 줄여본다.

# 오늘 날짜를 펼치고 하나씩 해본다

과제를 읽은 뒤 바로 작업할 수 있게 하루씩 나눴다.

매일 할 일은 영상 한 편을 만들고 다섯 곳에 올리는 것이다. 날짜별 과제는 그 안에서 하나씩 연습할 내용을 정한 것이다. 5일차가 대본을 고치는 날이라고 해서, 수정만 하고 업로드를 쉬는 것은 아니다.

> 오늘 만든 영상을 다섯 곳에 올리고 카페에 인증한다. 유튜브·클립은 프리즘 업로드를 확인해 사용하고, 나머지 세 곳은 직접 올린다. 못 올린 곳은 이유와 다음에 할 일을 적는다.

1. 먼저 준비물을 모은다. 상품과 쓸 영상이 준비돼 있는지 본다.
2. 실행 순서를 따라간다. 예시는 내 상품으로 바꿔 적용한다.
3. 프리즘에 입력할 문장도 내 상황에 맞게 바꾼다.
4. 완성 영상을 올린 뒤 카페에 오늘 한 일을 적는다.

허락을 기다리는 소스는 잠시 보류한다. 오늘 쓸 예비 소스가 있으면 그것으로 연습한다. 없으면 운영자에게 물어보고 아직 준비 중이라고 기록한다.

> 30일 목표는 영상 30개, 게시 150건, 인증글 30개다. 실제로 끝낸 수는 따로 적는다.

# 1일차 첫 한 편을 끝낸다

첫날에는 멋진 영상보다 한 편을 끝내는 데 집중한다. 저장과 업로드, 카페 인증까지 해본다.

## 시작하기 전에

프리즘·AI 연결, 게시 계정 5개, 카페 가입, 허락된 소스와 상품 정보.

## 오늘은 이렇게 해본다

1. 쓸 수 있는 영상 하나를 고른다. 처음에는 준비된 예제 파일로 시작해도 좋다. 상품명과 모델도 같이 적는다.
2. 불편한 상황, 쓰는 모습, 확인할 조건을 짧게 적는다. 마지막에는 상품 정보를 어디에서 볼 수 있는지 알려준다.
3. 리믹스 모드, 모델·음성·방향을 정해 초안을 만든다. 채팅 또는 설정 화면을 사용하고, 결과를 재생해 수정한다.
4. MP4를 저장해 끝까지 재생한다. 필요한 광고·제휴 표시와 플랫폼별 안내를 확인한 뒤 5곳에 게시한다.

> 프리즘에 이렇게 말한다
> 프리즘 사용법을 설명하고, 이 상품의 허락된 소스로 리믹스 초안을 만드는 설정을 안내해줘. 첫 작업은 한 편만 진행하자.

> 예를 들어
> 케이블 홀더라면 “선이 떨어지는 상황 → 선을 고정하는 모습 → 표면과 굵기 확인”으로 구성한다.

## 카페에 남길 내용

완성 파일, 상품 메모, 게시 링크 5개, 카페 인증글. 프리즘에 뭐라고 요청했고 어디를 고쳤는지도 짧게 적는다.

## 여기까지 했으면 된다

제품과 사용 방법이 보이고 저장 파일이 재생된다. 올린 곳과 못 올린 곳를 모두 기록한다.

> 오늘 만든 영상을 다섯 곳에 올리고 카페에 인증한다. 유튜브·클립은 프리즘 업로드를 확인해 사용하고, 나머지 세 곳은 직접 올린다. 못 올린 곳은 이유와 다음에 할 일을 적는다.

# 2일차 영상과 상품을 맞춰본다

상품이 비슷하게 생겼다고 같은 모델은 아니다. 영상과 연결할 상품을 나란히 놓고 본다.

## 시작하기 전에

오늘 사용할 허락된 소스, 상품 판매 정보, 전날 작성한 상품 메모.

## 오늘은 이렇게 해본다

1. 소스 속 제품의 브랜드·모델과 옵션을 찾는다. 외형만 보고 같은 상품이라고 단정하지 않는다.
2. 안내할 상품과 크기·구성·개수를 비교한다. 확인되지 않은 모델은 링크 후보에서 보류한다.
3. 소스 카드에 처음 올린 사람과 출처와 허락 범위를 적고, 상품 카드에 확인 날짜와 구매 전 조건 하나를 적는다.
4. 확인한 상품 정보로 오늘 대본을 작성한다. 프로그램으로 제작하고 5곳에 게시한 뒤 카페에 인증한다.

> 프리즘에 이렇게 말한다
> 소스와 상품 링크의 브랜드·모델·옵션이 일치하는지 확인할 항목을 정리해줘. 불확실한 값은 표시해줘.

> 예를 들어
> 케이블 홀더의 홈 개수나 규격이 다르면 같은 이름이어도 다른 옵션일 수 있다.

## 카페에 남길 내용

상품 카드 1장, 소스 카드 1장, 오늘 영상과 카페 인증. 프리즘에 뭐라고 요청했고 어디를 고쳤는지도 짧게 적는다.

## 여기까지 했으면 된다

영상의 제품과 설명·안내 상품이 일치한다. 모르는 값은 임의로 채우지 않는다.

> 오늘 만든 영상을 다섯 곳에 올리고 카페에 인증한다. 유튜브·클립은 프리즘 업로드를 확인해 사용하고, 나머지 세 곳은 직접 올린다. 못 올린 곳은 이유와 다음에 할 일을 적는다.

# 3일차 첫 문장을 바꿔본다

제품 이름부터 길게 말하지 않는다. 시청자가 겪을 만한 상황으로 시작해본다.

## 시작하기 전에

오늘 소스에서 문제나 사용 장면이 보이는 컷, 첫 문장 후보 2개.

## 오늘은 이렇게 해본다

1. 영상의 첫 3초에 무엇이 보이는지 확인한다. 로고나 포장만 나오면 사용 장면으로 시작할 수 있는지 본다.
2. 같은 상품으로 첫 문장 두 개를 쓴다. 하나는 불편, 하나는 사용 상황으로 만든다.
3. 첫 문장과 가장 잘 맞는 컷을 고른다. 없는 문제 장면을 있다고 설명하지 않는다.

# 6일차 구매 전 조건을 알려준다

4. 광고·제휴 표시와 동선을 확인해 게시한다. 카페에는 조건과 확인한 위치를 적는다.

> 예를 들어

4. 게시·인증 후 다음 날 줄일 방법 하나를 적는다.

> 프리즘에 이렇게 말한다
> 찾기·제작·개선·발행·인증의 시간 기록을 보고 줄일 단계 하나를 제안해줘.

> 예를 들어
> 게시 글을 매번 새로 썼다면 내일은 플랫폼별 문구 양식을 준비한다.

## 카페에 남길 내용

단계별 시간 5개, 다음 단축 방법, 오늘 영상과 카페 인증. 프리즘에 뭐라고 요청했고 어디를 고쳤는지도 짧게 적는다.

## 여기까지 했으면 된다

시간을 줄이려고 소스·사실·광고·제휴 표시 확인을 생략하지 않는다.

> 오늘 만든 영상을 다섯 곳에 올리고 카페에 인증한다. 유튜브·클립은 프리즘 업로드를 확인해 사용하고, 나머지 세 곳은 직접 올린다. 못 올린 곳은 이유와 다음에 할 일을 적는다.

# 조회수를 보고 다음 영상을 생각한다

숫자가 크다는 이유만으로 잘 팔린 영상이라고 판단하지 않는다.

처음에는 게시 다음 날의 조회수와 질문부터 본다. 사람들이 크기를 묻는지, 설치 방법을 궁금해하는지 적어두면 다음 주제가 생긴다.

| 볼 것 | 무엇을 알 수 있나 |
| --- | --- |
| 조회수 | 영상이 얼마나 재생됐는지 |
| 댓글·질문 | 사람들이 더 궁금해하는 내용 |
| 상품 클릭 | 상품 정보를 더 보려 했는지 |
| 주문·수수료 | 제휴 프로그램에 잡힌 구매와 수수료 |

플랫폼마다 조회수를 세는 방식이 다를 수 있다. 다섯 곳을 더한 숫자를 실제 사람 수로 보지는 않는다. 한 링크를 여러 영상이 같이 쓰면 어느 영상에서 주문이 왔는지도 정확히 모를 수 있다.

> “첫 장면이 상자뿐이라 사용법이 늦게 보였다. 다음에는 쓰는 모습부터 보여준다.”
> 이렇게 다음 행동까지 적으면 숫자를 확인한 보람이 있다.

아직 보지 않은 값은 “미확인”, 제공되지 않는 값은 “미제공”으로 적는다. 예상 수수료와 확정된 수수료, 실제 입금도 나눠 기록한다.

# 잘 안될 때는 이렇게 물어본다

막힌 부분 하나를 정해서 묻는다.

## 무엇부터 해야 할지 모르겠다

“쇼핑 리믹스 한 편을 만들고 싶어. 지금 준비해야 할 것부터 알려줘”라고 시작한다. 너무 많은 기능을 한 번에 배우려 하지 않는다.

## 영상이 마음에 안 든다

어디가 싫은지 정한다. 첫 문장이 길다면 줄여달라고 하고, 자막이 잘 안 읽히면 짧게 나눠달라고 한다. 다시 나온 영상도 직접 본다.

## 받은 영상을 써도 될지 모르겠다

처음 만든 사람과 사용 범위를 확인한다. 답이 없으면 다른 소스를 고른다. 내려받을 수 있다는 것과 다시 올려도 된다는 것은 다르다.

## 한 곳에 업로드가 안 된다

다른 곳은 먼저 올리고, 안 된 곳은 오류와 다음에 할 일을 카페에 적는다. 생성이 안 된 건지 업로드가 안 된 건지도 나눠본다.

## 자동 업로드 메뉴가 안 보인다

사용하는 버전과 연결된 계정을 확인한다. 유튜브·클립 외의 세 곳은 직접 올리는 방법으로 진행한다.

# 30일 뒤에도 다음 한 편을 만들 수 있게

잘된 영상뿐 아니라 고친 과정도 남긴다.

완주하고 나면 영상만 모아두지 않는다. 어떤 상품을 골랐고, 어떤 소스를 썼고, 어디를 고쳤는지도 같이 남긴다. 다음 영상을 만들 때 그 기록이 도움이 된다.

잘 읽혔던 첫 문장, 보기 쉬웠던 장면, 자주 나왔던 질문을 찾아본다. 그대로 복사하기보다 다음 상품에도 쓸 수 있는 방법을 골라둔다.

> 다음에 만들 상품 세 개와 질문을 적는다.
> 그중 준비된 하나부터 다시 시작하면 된다.

현재 소개된 기능과 추가될 기능은 나눠 적었다. 가격·토큰·AI 연결도 실제 이용 안내를 본다. 조회수나 수익, 계정 정지 방지를 보장하는 책은 아니다.

> 챌린지 일정, 질문·피드백, 비용, 카페 주소는 운영자가 별도로 안내한다.

# 음악이나 화면이 마음에 안 들면 바꿔본다

어디를 바꿀지 말하면 수정하기 쉽다.

1. 음악을 찾을 때는 “잔잔한 곡 세 개를 추천해줘. 출처와 상업적 사용 범위도 알려줘”라고 요청한다.
2. 효과음이 필요하면 어떤 장면에 넣을지 말한다. 소리가 너무 크지 않은지도 본다.
3. 큰 효과가 거슬리면 “사용 장면과 짧은 자막 위주로 바꿔줘”라고 한다.
4. 마음에 든 설정과 사용한 음악 정보는 저장해둔다.

무료 음악이라고 모든 플랫폼의 광고 영상에 쓸 수 있는 것은 아니다. 사용 범위를 확인한다. 템플릿도 다른 사람의 화면을 통째로 복제하기보다 원하는 구도와 움직임을 설명한다.

> 일레븐랩스 구독 연결, 내 목소리, 에이전트 창 안에서 편집하는 기능은 준비·예정 항목으로 안내돼 있다. 제공 여부부터 확인한다.

# 익숙해진 작업만 예약해본다

처음에는 한 번 끝까지 해보고 반복한다.

1. 한 편을 만들어 올린다. 계정과 제목, 상품 정보까지 맞는지 본다.
2. 반복할 일을 정한다. “매일 오전 10시에 상품 후보를 찾아줘”처럼 작업과 시간을 말한다.
3. 검색만 반복할지 발행까지 할지 나눈다. 상품·링크·허락이 바뀌면 다시 확인한다.
4. 예약 작업이 실제로 끝났는지 보고 오류가 있으면 남긴다.

작업을 여러 개 돌리고 싶어도 적은 수부터 늘린다. PC가 버거워하면 하나씩 처리한다. 병렬 기능이 있다는 말이 내 PC에서도 같은 수를 처리한다는 뜻은 아니다.

> 프로그램이 예전 설정을 기억해도 상품과 계정, 사용 허락은 다시 본다. 바뀐 정보는 내가 알려줘야 한다.

# 긴 영상이나 글도 필요하면 써본다

쇼핑 영상에 익숙해진 뒤 해도 늦지 않다.

## 긴 영상에서 짧게 만들기

내 영상이나 편집해서 올려도 되는 긴 영상을 준비한다. 핵심 구간을 고르고 앞뒤 내용을 본다. 짧게 자르면서 원래 뜻이 달라지지 않았는지 확인한다.

## 글과 키워드 살펴보기

사이트의 자료나 키워드 분석을 참고할 수 있다. 검색량과 경쟁도 같은 숫자는 출처와 기준 날짜도 본다. 글을 수집하거나 제목을 바꿀 수 있다고 원문을 그대로 복제해도 되는 것은 아니다.

> 커뮤니티 사연으로 영상을 만들 때도 사실과 개인정보를 확인한다. 익명으로 올라왔다는 이유만으로 실제 사건이라고 단정하지 않는다.

# 추가로 드는 비용도 미리 알아둔다

챌린지 참가비와 프로그램 요금은 같은 항목이 아니다.

| 항목 | 확인할 것 |
| --- | --- |
| 프리즘 | 월간·연간·기존 영구권의 사용 범위 |
| 채팅 | 요금제에 포함된 토큰과 추가 사용 조건 |
| AI | 구독 계정·API 연결과 별도 비용 |
| 생성 도구 | 구글 플로우 등 연결과 요금 |
| 원격 | 프로 요금제는 원격 기능이 빠져 있다는 안내 |
| 운영체제 | Windows 우선, Mac 이후 예정 안내 |

밖에서 접속하거나 설정을 동기화할 때는 접근 권한도 확인한다. 비밀번호와 API 키, 원격 접속 정보는 공개된 곳에 남기지 않는다.

IP나 프록시 설정이 있다고 계정이 안전하다는 뜻은 아니다. 플랫폼 이용 조건과 계정 연결 안내를 따른다. 이 책에서는 탐지를 피하거나 정지를 막는다고 약속하지 않는다.
